# Security Policy

## Supported Versions

We actively maintain the latest stable branch. Please ensure you are using the most recent version to receive security updates.

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not open a public issue**. Instead, report it privately by emailing [security@open3diy.org](mailto:security@open3diy.org). Include as much detail as possible to help us understand and address the issue quickly.

We aim to respond to all security reports within 72 hours. Once the vulnerability is confirmed, we will work to release a fix as soon as possible and acknowledge your contribution if desired.

## Security Best Practices

- Always use the latest version of the project.
- Review dependencies for known vulnerabilities.
- Never share sensitive information (such as API keys or credentials) in public repositories or issues.

## Disclosure Policy

We follow a responsible disclosure process. After a vulnerability is reported, we will coordinate with the reporter to validate and resolve the issue before public disclosure.

Thank you for helping us keep this project secure!
